### サイコロのコード
```python
import random

# 1〜6までのサイコロを振る
r = random.randint(1, 6)
print(f"サイコロの目は {r} です！")

# 出た目でメッセージを変える
if r == 6:
    print("大当たり！今日はかなりラッキー！")
elif r >= 4:
    print("いい感じ！もう少し頑張ろう！")
else:
    print("次はもっと運が向くかも！")
```
